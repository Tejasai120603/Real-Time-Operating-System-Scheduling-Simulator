🎓 WHAT THIS PROJECT DEMONSTRATES:

✓ Task Creation & Scheduling
  - SensorTask (Periodic, 500ms, Medium Priority)
  - ControlTask (Periodic, 200ms, High Priority)
  - LoggerTask (Aperiodic, Event-driven, Low Priority)
  - MonitorTask (Periodic, 1000ms, Medium Priority)

✓ Inter-Task Communication
  - Semaphores for signaling
  - Mutexes for data protection
  - Shared memory with synchronization

✓ Real-Time Performance Metrics
  - Latency measurement
  - Response time tracking
  - Jitter calculation
  - Throughput monitoring

✓ Real-World Simulation
  - Sensor data collection (Temp, Pressure, Humidity)
  - Control logic with critical thresholds
  - System health monitoring
  - Event logging

1. Task Creation Messages
   ✅ SensorTask created
   ✅ ControlTask created
   ✅ LoggerTask created
   ✅ MonitorTask created

2. Real-Time Execution
   [SensorTask] Read: Temp=45°C, Press=62 kPa, Humid=78%
   [ControlTask] Command: Actuator=0, Value=50
   [LoggerTask] [MEDIUM] Sensor Reading - T:45 P:62 H:78

3. Health Monitor Reports (Every 1 second)
   Shows: Operations count, latency stats

4. Final Statistics (After 30 seconds)
   Shows: Total operations, avg/max/min latency, jitter

⚙️ CUSTOMIZATION:

To modify simulation parameters, edit rts_simulation.c:

#define SIMULATION_DURATION_SEC 30     // Simulation time
#define SENSOR_PERIOD_MS 500           // Sensor frequency
#define CONTROL_PERIOD_MS 200          // Control frequency
#define MONITOR_PERIOD_MS 1000         // Monitor frequency
#define CRITICAL_TEMP_THRESHOLD 75     // Temp alert level
#define CRITICAL_PRESSURE_THRESHOLD 80 // Pressure alert level

🆘 TROUBLESHOOTING:

Problem: Build fails with "gcc not recognized"
Solution: Install MSYS2/MinGW64 from https://www.msys2.org/

Problem: No output when running
Solution: Check if rts_simulation.exe was created

Problem: Want to run without rebuilding
Solution: Use run_rts.bat instead of build_rts.bat
